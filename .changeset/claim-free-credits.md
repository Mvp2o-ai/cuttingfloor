Two new tools on the hosted service. credits.claim activates the user's free credits, keeps one sentence on what they want to make with video, and returns their balance; it is safe to call any number of times, never changes a balance, and editing never depends on it. A connected assistant offers it when the user hasn't asked for anything yet. support.contact sends the cuttingfloor team a message about anything that failed, couldn't be done, or would help, and always answers with an acknowledgement.

The admin API (1.1.0) shows each account's use case and when it was given.
