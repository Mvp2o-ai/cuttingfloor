Every account has its own link, cuttingfloor.ai/r/<code>, with a code made from the account id alone. The link opens a page of what cuttingfloor makes, with sign-up, and leaves the same 30-day cookie a tagged link does; a sign-up through it keeps the code as `referred_by`. A file's watch page shows "Made with cuttingfloor" with its owner's link. The admin API (1.11.0) gives each account a `referral`: its code and link, the code and account that brought it, and how many people its link brought who signed up, ran a tool and started an export. The privacy policy names the referral code and who referred whom. Nothing in the tools, their results or the chat views changes.
