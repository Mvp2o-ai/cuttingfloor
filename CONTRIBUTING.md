# Contributing

1. Node 24+, pnpm 10 (`corepack enable`).
2. `pnpm install`, then `pnpm check`.
3. Branch from `main`, keep changes focused, add tests, and add a changeset for user-facing changes.
4. Open a pull request; CI runs lint, typecheck and tests.

Security issues: see [SECURITY.md](SECURITY.md), not the issue tracker.
